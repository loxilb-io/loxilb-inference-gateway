Warnings
{{- if $authPools }}
  ! inference.pools[].auth is set on {{ $authPools }}. kube-loxilb carries
    loxilb.io/api-key-auth and loxilb.io/jwt-auth-profile into the loxilb rule
    from feat/auth-annotation (830fa59) on; an OLDER kube-loxilb installs these
    rules WITHOUT the authentication declared here. The chart cannot tell which
    kube-loxilb runs: check `kubectl -n {{ .Release.Namespace }} get crd jwtauthprofiles.jwtauthprofile.loxilb.io`
    is served and the rule reads back with api_key_auth.
{{- if $jwtProfiles }}
  ! JWT mode needs a cluster-scoped JWTAuthProfile for each of: {{ join ", " $jwtProfiles }}.
    kube-loxilb holds the rule (ProfileNotFound) until the profile exists and is
    programmed on every gateway. This chart version does not render profiles yet
    (phase 2 does); create them by hand, see charts/kube-loxilb/README.md.
{{- end }}
{{- if and $igw.enabled (not $hasKeyStore) }}
  ! loxilb-igw runs without an API-key store (no --aikey-db-host in
    loxilb-igw.loxilb.extraArgs). The gateway fails closed on every request
    that carries an identity but has no store to check it against: a VERIFIED
    token is refused 503 policy_store_unavailable. JWT-only setups need the
    store too (phase 2 bundles PostgreSQL; until then point --aikey-db-* at one).
{{- end }}
{{- end }}
{{- if $epp.enabled }}
  ! Every pool names the Endpoint Picker Service {{ $epp.name }}:{{ $epp.port }} (failureMode {{ $epp.failureMode | default "FailOpen" }}).
    This chart does not deploy it: install the picker so that the Service exists
    in each pool's namespace. Until it does, the pool's ResolvedRefs is False
    and {{ if eq ($epp.failureMode | toString) "FailClose" }}every request is answered 503 epp_unavailable{{ else }}loxilb's own selection serves{{ end }}.
    The gateway calls the picker only if it lists "epp" in /version features
    ({{ include "loxilb-inference-gateway.loxilbURL" . }}/netlox/v1/version);
    on one that does not, kube-loxilb {{ if eq ($epp.failureMode | toString) "FailClose" }}refuses the rule (EndpointPickerUnsupported){{ else }}sends the rule without the picker{{ end }}.
{{- end }}
